# 💰 Expense Tracker

A modern, responsive, and intuitive web application designed to track personal income, expenses, and current balance with persistent local storage using vanilla **HTML5**, **CSS3**, and **JavaScript**.

🔗 **Live Demo:** [khaledcherfouhi2006-maker.github.io/Expense-Tracker](https://khaledcherfouhi2006-maker.github.io/Expense-Tracker/)

---

## ✨ Features

- **Real-Time Balance Calculation:** Automatically computes total balance, aggregate income, and total expenses with dynamic currency formatting (`$ USD`).
- **Income & Expense Classification:** Visual indicator tags (green for income, red for expenses) and slide-in entry animations.
- **Transaction History:** Displays a chronological log of all added transactions with a custom styled scrollbar.
- **Delete Transaction:** Remove any logged entry with instant balance and summary recalibration.
- **Persistent Data (LocalStorage):** Saves all transaction records locally so data remains intact across page reloads.
- **Modern UI & Responsive Design:** Built using modern CSS gradients, cards, hover effects, and a mobile-friendly grid layout.

---

## 🛠️ Built With

- **HTML5:** Semantic document structure for dashboards, transaction forms, and summary cards.
- **CSS3:** Custom layout using CSS Grid and Flexbox, Google Font (Poppins), smooth transitions, animations, and responsive media queries.
- **JavaScript (ES6):** State management, DOM manipulation, array higher-order functions (`reduce`, `filter`), and the `Intl.NumberFormat` API.
- **GitHub Pages:** Static site hosting and deployment.
